# Typing Speed Test

A simple Python project to test typing speed and accuracy.

## Features
- Displays a random sentence.
- Measures typing time.
- Calculates typing speed in words per minute (WPM).
- Calculates typing accuracy.

## Requirements
- Python 3.x

## How to Run
1. Save the code as `typing_test.py`.
2. Open the terminal in the project folder.
3. Run the command:

   ```bash
   python typing_test.py
   ```

4. Type the displayed sentence and check your results.

## How It Works
The program selects a random sentence and measures how long you take to type it. It then displays your typing time, word count, typing speed, and accuracy.
